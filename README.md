# Pasport Checker

Небольшая программа с окном, которая сама следит за электронной очередью
ДП «Документ» (pasport.org.ua) и сообщает, как только появится свободная дата
записи **не позже нужной** — например, до 02.10.2026 включительно.

Сейчас проверяются два адреса (список легко расширяется):

| Город   | Страница |
|---------|----------|
| Варшава | https://warszawa.pasport.org.ua/solutions/e-queue |
| Гданськ | https://gdansk.pasport.org.ua/solutions/e-queue |

## Как это работает

Программа открывает страницу записи в настоящем браузере (Chromium),
выбирает в списке «Послуга» нужную услугу, дожидается, пока подгрузится
список «Обрати день», и читает все доступные даты. Если хотя бы одна дата
не позже указанной — на компьютер приходит уведомление, звучит сигнал,
а окно программы поднимается поверх остальных.

Браузер нужен потому, что даты на сайте подгружаются скриптами: в исходном
HTML их нет.

## Установка (один раз)

Нужен Python 3.9 или новее — https://www.python.org/downloads/
При установке на Windows обязательно отметьте галочку **«Add Python to PATH»**.

* **Windows** — двойной клик по `install.bat`
* **macOS / Linux** — `./install.sh` в терминале

Скрипт поставит Playwright и браузер Chromium (примерно 150 МБ).
То же самое можно сделать кнопкой **«Установить браузер»** прямо в программе.

> Если Chromium скачивать не хочется, а на компьютере уже есть Google Chrome
> или Microsoft Edge — программа сама попробует запустить их.

На Linux дополнительно может понадобиться tkinter: `sudo apt install python3-tk`

## Запуск

* **Windows** — двойной клик по `run.bat`
* **macOS** — двойной клик по `run.command`
* **Linux** — `./run.sh`

## Что в окне

* **Нужна дата не позже (включительно)** — та самая контрольная дата, по умолчанию `02.10.2026`.
* **Проверять каждые (минут)** — как часто перепроверять сайты.
* **Проверить сейчас** — разовая проверка.
* **Старт / Стоп** — включить постоянное слежение. Программу можно свернуть,
  она продолжит работать и позовёт, когда найдёт.
* **Скрывать окно браузера** — снимите галочку, если хотите видеть, что происходит.
* **Вкл/выкл сайт** — временно исключить адрес из проверки.
* **Открыть сайт** — открыть страницу записи в обычном браузере, чтобы дозаписаться руками.
* Таблица показывает по каждому адресу ближайшую дату и количество подходящих,
  журнал внизу — подробности. Он же пишется в файл `checker.log`.

Найденная дата подсвечивает строку зелёным и выводит уведомление. Об одной и
той же дате программа напоминает не чаще, чем раз в 2 часа, чтобы не надоедать.

## Настройки (config.json)

Файл создаётся рядом с программой при первом сохранении. Кнопка
**«Открыть config.json»** откроет его в редакторе; после правок перезапустите программу.

```json
{
  "deadline": "02.10.2026",
  "interval_minutes": 15,
  "mode": "browser",
  "headless": true,
  "notify_repeat_minutes": 120,
  "sound": true,
  "timeout_seconds": 60,
  "sites": [
    {
      "name": "Варшава, Єрусалимські алеї 179",
      "url": "https://warszawa.pasport.org.ua/solutions/e-queue",
      "service": "Закордонний паспорт",
      "enabled": true
    }
  ]
}
```

* `service` — часть названия услуги из списка «Послуга». Значение `"*"`
  означает «проверять все услуги подряд».
* `mode` — `browser` (надёжно) или `http` (быстро, но видит только те даты,
  что уже есть в HTML страницы).
* `browser_path` — необязательный путь к своему браузеру, например
  `"C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe"`.

### Добавить ещё один город

Допишите блок в `sites` — адрес страницы у всех отделений одинаковый по формату:

```json
{ "name": "Краків", "url": "https://krakow.pasport.org.ua/solutions/e-queue",
  "service": "Закордонний паспорт", "enabled": true }
```

## Первый запуск

Первый раз стоит запустить проверку со **снятой** галочкой «Скрывать окно
браузера» — вы увидите, как программа выбирает услугу и читает даты, и сразу
поймёте, всё ли она делает правильно. Дальше галочку можно вернуть.

В журнале видно, какие услуги нашлись на сайте: если нужная называется иначе,
впишите часть её названия в `config.json` (поле `service`).

## Если что-то не работает

| Что видно | Что делать |
|-----------|-----------|
| «не удалось запустить браузер» | Запустите `install.bat` / `install.sh` или кнопку «Установить браузер» |
| «услуга … не найдена» | В журнале перечислены доступные услуги — впишите нужную в `config.json` |
| «свободных дат нет» | Так и есть: сайт не предлагает ни одной даты по этой услуге |
| «даты не найдены в HTML» | Это режим `http`; переключитесь на `browser` |
| «на странице не появилась форма записи» | Снимите галочку «Скрывать окно браузера» и посмотрите, что показывает сайт: бывает проверка «я не робот» или технические работы |
| Окно не открывается на Linux | `sudo apt install python3-tk` |

Программа только смотрит на страницу и читает даты — она ничего не бронирует
и не отправляет ваши данные. Записываться нужно самому, по кнопке «Открыть сайт».
